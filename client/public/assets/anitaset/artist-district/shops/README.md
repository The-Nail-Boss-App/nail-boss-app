# Nail Shop Assets

Artist identity is their work: Signature Nail avatars must feature nail art, not selfies, faces, initials, or substitute logos.

## Founder Collection production assets

Each approved Founder Collection shop requires these two image types:

- **Shop cover image** — supports a wide card crop and contains no baked-in shop copy.
- **Signature Nail avatar** — uses a consistent square canvas with the featured nail design centered for circular cropping.
