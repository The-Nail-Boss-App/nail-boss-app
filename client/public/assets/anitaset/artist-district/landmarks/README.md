# Landmark Assets

## Required assets

- `artist-district-fountain-v1.png` — Founder-approved production artwork for the Artist District fountain landmark (installed).
- `artist-district-gateway.png` — transparent or cleanly isolated district entrance landmark.
- `artist-district-directory-sign.png` — district directory or wayfinding landmark.
- `artist-district-community-marker.png` — visual marker for the Living Community area.

Landmarks should share one architectural visual language, retain clean edges at responsive sizes, and contain no baked-in navigation labels or live community metrics.
